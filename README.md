# Кулинарный помощник: Gradio + YandexGPT

Веб-интерфейс на Gradio, который по описанию блюда генерирует список покупок (опционально — с пошаговым рецептом) через YandexGPT API.

## Структура проекта

- [`gradio_app.py`](gradio_app.py) — UI на Gradio: поля «Что готовим», «На сколько человек», «Формат ответа» и кнопка генерации.
- [`llm.py`](llm.py) — работа с API: сборка промпта, вызов модели, повтор при 5xx/сетевых ошибках, обработка ошибок и валидация ввода.
- [`requirements.txt`](requirements.txt) — зависимости проекта.

## 1. Команды запуска

### Подготовка окружения

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows (cmd/PowerShell)
source .venv/bin/activate       # Linux/macOS
pip install -r requirements.txt
```

### Переменные окружения

Создайте файл `.env` в корне проекта:

```env
YANDEX_GPT_API_KEY=ваш_api_ключ
YANDEX_GPT_FOLDER_ID=ваш_folder_id
```

Переменные читаются в [`llm.py`](llm.py:14) через `python-dotenv`.

### Запуск приложения

```bash
python gradio_app.py
```

или

```bash
gradio gradio_app.py
```

После запуска интерфейс доступен по адресу `http://127.0.0.1:7860`.

### Быстрая проверка логики без UI

```bash
python -c "from llm import generate_response; print(generate_response('паста карбонара', '2', 'Список продуктов'))"
```

## 2. Проверки сценария

Логика проверок реализована в [`generate_response()`](llm.py:91). Первые две проверки выполняются **до** обращения к API — при их срабатывании запрос в YandexGPT не отправляется.

### 2.1. Нормальный текст → получаете список покупок

**Ввод:**
- «Что готовим»: `паста карбонара`
- «На сколько человек»: `2`
- «Формат ответа»: `Список продуктов`

**Ожидаемый результат:** в поле «Ответ» появляется список продуктов с количеством, рассчитанным на 2 порции (ответ модели). При выборе формата `Список + шаги` дополнительно возвращается пошаговый рецепт (5–8 пунктов).

### 2.2. Пустой текст → сообщение в UI, вызова API нет

**Ввод:**
- «Что готовим»: пустая строка или одни пробелы (например, `"   "`)
- Остальные поля — любые

**Ожидаемый результат:** в поле «Ответ» выводится `Напишите, что хотите приготовить.`

### 2.3. Длинный текст → сообщение в UI, вызова API нет

**Ввод:**
- «Что готовим»: текст длиннее 100 символов (можно вставить любой абзац или повторяющийся текст)
- Остальные поля — любые

**Ожидаемый результат:** в поле «Ответ» выводится `Слишком длинный текст — сократите или разбейте на части.`

## 3. Как воспроизвести ошибку

Пример: **убрать API-ключ**.

1. Откройте `.env` и удалите (или закомментируйте) строку с ключом:

   ```env
   # YANDEX_GPT_API_KEY=ваш_api_ключ
   YANDEX_GPT_FOLDER_ID=ваш_folder_id
   ```

2. Перезапустите приложение:

   ```bash
   python gradio_app.py
   ```

3. Введите корректный запрос (например, `паста карбонара`, `2`, `Список продуктов`) и нажмите «Сгенерировать список покупок».

**Ожидаемый результат:** в поле «Ответ» появляется сообщение `Не настроен доступ к сервису.`

Другие способы воспроизвести ошибки:

- Указать неверный `YANDEX_GPT_FOLDER_ID` → ошибка 4xx от API → сообщение `Не настроен доступ к сервису.`
- Отключить интернет или указать неверный `BASE_URL` → `APIConnectionError` → сообщение `Не удалось получить ответ. Попробуйте ещё раз.` (после одной повторной попытки, см. [`_call_with_retry()`](llm.py:67)).
